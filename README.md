**`Integration & Backend Engineer`**

I design and build resilient integration flows, secure API gateways, and high-throughput backend middleware that reliably connect disparate enterprise systems.

Currently bridging the gap between legacy systems and modern cloud ecosystems using **SAP Integration Suite (CPI & API Management)** and high-performance **Node.js middleware architectures**.

---

## ⚡ What I'm Building & Integrating

* **Enterprise Orchestration:** End-to-end integration flows in **SAP CPI** using dynamic routing, content modifiers, custom Groovy scripting, and complex message mapping.
* **Resilient Middleware:** High-concurrency integration adapters and microservices using **Node.js, Express, and Redis** for message queuing (BullMQ) and distributed locking.
* **API Governance:** Secure API Proxies with **SAP API Management**, enforcing traffic policies (Spike Arrest, Quotas), JSON threat protection, and OAuth 2.0 / API Key authentication.
* **B2B / EDI & Connectivity:** Designing secure B2B communication pipelines utilizing AS2, SFTP, SMB, SOAP, and REST adapters.
* **Performance & Reliability Engineering:** Validating integration pipeline throughput and resilience using **k6, Postman, and Jest** to ensure zero-data-loss under high stress.
